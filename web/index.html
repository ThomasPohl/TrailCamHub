TrailCamHub · ESP32-S3

Firmware installer

Install the latest TrailCamHub BLE proof-of-concept firmware and inspect its serial logs.

Install firmware

  1. Connect your ESP32-S3 board to this computer with a USB data cable.
  2. Select the board's serial port when your browser asks.
  3. Confirm the installation in the browser dialog.
Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

This installs the current CI build. The default firmware scans for the configured BLE camera and discovers its control characteristic; it does not send a Wi-Fi-enable command.

Serial console

After installation has finished and the installer has released the port, connect here to view ESP-IDF logs at 115200 baud.
