Set up your hub

Install the firmware, answer a few questions and check that everything works. You need a desktop Chrome or Edge and a USB data cable.

Setup assistant

1 · Which board do you have?

Loading the board list…

2 · Install the firmware

Connect the board with a USB data cable, press Install and choose its serial port. Installing erases the hub's settings only if you tick that in the dialog.

Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

The current release build (…). Older and development builds are under Advanced.

The web installer does not offer an image for this board yet. Flash the image from the latest release with esptool, then continue.

3 · Connect to the hub

After installing, wait a few seconds, then connect. A hub on battery sleeps most of the time: after a reset it stays awake for ten minutes.

              Install the camera mock
              
            
              The mock stands in for the camera on the bench: it advertises over BLE like a TC100, opens its access point and answers the hub's requests (media list, thumbnails, photos, videos) with recorded data. It runs on a classic ESP32-WROOM-32D board without an SD card. See tools/camera_mock.
              
            
                
              
              1. Connect the board with a USB data cable. Do not use the board that runs the hub firmware, or the hub is overwritten.
                2. 
              
              2. Press Install camera mock and choose the serial port. If the flashing does not start, hold BOOT while the dialog connects.
                3. 
              
              3. Press Connect at the left, after the installation.
                4. 
            
              
            
              
              
              
              
               
              
            
              
            
              
              Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge.
              Open this page over HTTPS and allow serial-port access in your browser.
