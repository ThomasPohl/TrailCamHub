        Install firmware

        1. Connect your board to this computer with a USB data cable.
        2. Choose the board, a build version and a variant below, then select the board's serial port when your browser asks.
        3. Confirm the installation in the browser dialog.

         

        This build has no image for the chosen board (builds before the per-board installer have only the ESP32-S3-A7670E-4G). Choose a newer build.

        Development build

        Verbose serial logs (INFO level). Use this to watch the camera protocol and read responses in the serial console below.

        Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

        Release build

        Size-optimized, warnings-only logging. Use this for normal operation.

        Use a desktop Chromium-based browser that supports Web Serial, such as Chrome or Edge. Open this page over HTTPS and allow serial-port access in your browser.

        Each build is the CI firmware for the chosen board at that commit. The firmware activates and talks to a camera only where those connections are authorized.

        Device setup

        Store the hub's settings and start a scan over the USB connection. A scan wakes the camera, reads its new recordings and, if the uplink is configured, uploads them to the backend over your Wi-Fi. With the autonomous profile the hub also reads the camera and checks in on its own schedule and sleeps in between; after a power-on or reset it stays awake for ten minutes (press reset on the board to connect again).

          Live protocol view

          Decodes the serial log as it streams in: the camera session's progress, the parsed media list (a video and its photo grouped as one capture, with the thumbnail the firmware prints over serial), and the raw thumbnail/photo bulk frames. Connect the serial console below to drive it live, or replay a bundled sample.

            Bulk frames

            Thumbnail/photo data on the bulk channel (D0/D1 subtype 0x03/0x04). Decoded from the recon hex dump: ARTEMIS record header, 72-byte media header, JPEG start.
